# 世界观与修行九境

首卷原型已开放锻骨、舒筋、贯劲、听息。后五境用于后续卷。首胜目前通过手札对白与战场物件反馈，人物过场可沿用下文的故事线。

本册定下人物身世、四卷因果、九境门槛与传承类别。战斗系数见[玩法与数值设计](玩法与数值设计.md)，装备组合见[流派构筑与长线玩法](流派构筑与长线玩法.md)。后卷调整敌人气血、学习价格或演出速度时，沿用这里的破境顺序和能力来源。

## 第一盏灯

青芦村的渡口有个老规矩，末班船靠岸，船夫便摇三下铜铃，山上的守灯人听到铃声才收灯。七年前一场大水冲走渡船。村里年年补写溺亡者姓名，祠里却始终多着一块无字木牌。今年入秋，铃又响了，次次都从河底传来。

玩家从给师父替一夜班开始。行囊里有短刀、旧灯和一本被水泡过的巡簿。第一页留着师父的笔迹：“听见第三声，数一数岸上还有几个人。”玩家想弄清当年谁没上岸，也要先让眼前的人能够平安过河。

青芦村、纸马驿、云栈和山上的总灯房，原是同一条旧驿路的四段。山里水急、夜雾来得早，每站都有守灯的本地人。渡口以铃报平安，驿站以纸封记交接，云栈以风灯指落脚处，总灯房把各站回报抄入巡簿。村民会扎灯、修桥、掌船，陆婆能听懂旧铃却无法听见妖息。后来阿照能御风，仍然需要陆婆来认七年前的船名。地理始终相连，进入仙途只是让原先走不到的路变得可达。

七年前师父守山灯，收到三声便照例收灯。事后他才知道，摆渡学徒阿满曾折返救人，那三声只报了第一船。他在巡簿上添了数人的叮嘱，此后一直追访各站。开篇那一夜，师父去上游核对来铃，阿照接下村里的班。村中妖患各有自己的来由；水灾让渡口、驿站、栈道的几件未竟之事撞在一起。后卷沿路查明它们如何相连，首卷写回阿满姓名的结论永久成立。

## 人、妖与道行

**阿照天生有一种罕见的禀赋，名为「观化」。** 师父教她握刀、守架、辨路。村里的武者也能随师习武、读谱拆招，凭自己的修为入道。阿照的特别之处在于，亲身接过妖魔的一招后，她有时会在自己身上感到对方运转这一招的经过。哪怕双方的筋骨、感官迥异，她也能循着这份记忆，把对方的本领练成人身可用的招式。

**黑风岭是第一次觉醒。** 山君退进松林，挑油人已经能听见自己的扁担吱呀作响，阿照胸口却还留着虎啸发出前短短的一顿。她认出那是山君收势换气的一瞬，将它记进巡簿，才有了《镇山喝》的第一笔。她赢下这一战靠的是师父教的短刀和守式。第一次用自己的声音截住河伯回浪时，玩家才见到这份天赋真正练成后的样子。

- **妖有来处。** 山君是受伤后占据山道的老虎，芦偶是缠住旧面具的水草，借面娘娘因村民多年供奉无名牌位而成形。山灵、器物、积念都可生妖；有的害人，有的只是反复做着生前最后一件事。地方习俗决定妖会做什么。
- **灯认路，簿记势。** 巡簿可以交给旁人，旁人能读到阿照写下的虎啸招谱；那一瞬胸中换气的记忆，只有亲历觉醒的阿照能重温。她可以把已经练成的人身招式教给别人。后来者若想自行参透另一种妖魔的本命神通，仍需另有机缘。
- **道行是经验。** 玩家把反复过招的心得用在筋骨、招式或识妖上。消耗的是尚待消化的心得，已悟的境界永久保留。村民不出售道行，大妖也不会随身携带一本用自己名字命名的秘籍。
- **天赋与境界各有用处。** 观化让阿照悟得妖魔传承，道行让她把心得练到入门和精通。凡俗阶段，她的身体已能承载武技与身法；到了听息，才有运息施展神通的根基。若日后先遇见高境妖魔，可以先记下招谱，达到招谱所需境界后修习。天赋常驻，不占招式位。

小妖反复出现，是一地仍会生出新的草木、器物小妖。大妖首胜只登记一次，陆婆复渡、石生还灯等变化永久保留。《斩妖录》的重演可补悟真实见过的招式。后卷的“异相”是阿照在灯下推演“若它早一轮起浪，我怎么接”，可更换敌方招谱，村中人的经历以主线首胜为准。

## 一个人的境界与一门招的修为

人物只有一条九境序列。锻骨到贯劲是凡俗武道，听息到坐忘开始修仙，御风到逍遥进入仙途。武学是传承类别，也是凡人入道的根基。文案写“阿照已入贯劲，《镇山喝》已精通”，角色面板和招式页各显示自己的进度。

| 玩家所见 | 取得与成长 | 边界举例 |
|---|---|---|
| 境界 | 完成确定性的剧情门槛，按顺序花道行突破，永久保留 | 入听息要贯劲、河伯首胜和道行。娘娘掉《照影》之前，阿照已经能靠听息辨出真身。 |
| 武学 | 人间有师承、招谱和自创武学；阿照另可通过观化把妖魔武技练成人身招式，装武学位 | 《镇山喝》取自山君啸前换气的一瞬。日后《挑灯诀》以刀尖挑中符印；即使没带符，基础刀招也能独立出手。 |
| 身法 | 习得移动、卸力或落脚的技巧，装身法位 | 河伯能驱浪；阿照从它的落脚学到《听潮步》，借浪避击。舒筋随境提供的退步可替换为这门身法。 |
| 神通 | 修行人可依本门法诀修习；阿照还可观化妖魔神通，听息起凭自身修为施展，装神通位 | 听息使阿照能在烛偏时辨认真身；借面娘娘的传承则教她以《照影》主动显形。用旧灯照路是普通动作。 |
| 架势与普攻 | 开局就能选守式、攻式；每轮挥一次短刀 | 架势独立于传承槽，凡俗短刀到仙途仍能吃到破绽和显形带来的收益。 |

**同一传承有四个动作。** 悟得时卷中出现可研读的招谱；花道行学习后入门；战外装备后才按谱释放；再花道行精通则增加卡面写明的效果。山君首胜必得招谱对应天赋初醒。此后胜过大妖只代表解决了这一战，能否记全一门本领另行结算；灯下重演让阿照逐次补全遗漏。精通不会自动改变首发轮或间隔。到逍遥时，她能把观化得来的两门传承合成自己的本命招，再把自己的招谱留给后来人。

## 第一卷的人

| 人物 | 所求 | 怎样让玩家认识这个人 |
|---|---|---|
| 阿照，守夜学徒 | 替师父守完七年前未完的一班夜 | 靛青短褂、枣红头巾、补过两次的灯。每次破境仍提同一盏灯。首版采用固定女主形象。 |
| 陆婆，掌渡人 | 让停渡的河重新载人 | 初见时坐在空码头搓绳，河伯退去后解开缆绳，成为第一个撑船过河的人。 |
| 石生，守祠童子 | 还清每一盏供灯的愿 | 他知道无名牌位原为寻亲者共用。白烛庙一役之后，他把各家的灯亲手送还。 |

山君封住进山取灯油的小道，河伯拦住渡船，娘娘借走祭灯人的面貌。顺着灯油、船和灯火，三个妖案连成一桩旧事。终章揭晓，无字牌留给那晚折返救人的摆渡学徒。村民各自记得他最后一面，娘娘才生出百般面孔。首胜后，陆婆将学徒的乳名“阿满”写上木牌。第二卷的引子只留一个，山外另一座渡口也响起第三声铃。

## 九境

下列顺序、题辞和玩法均为原创。早期用武人故事、导引动作作参照，后期借诸子古籍的意象。古籍与创作的对应关系列于表后。

| 境界 | 破境题辞 | 玩家真正学会的事 |
|---|---|---|
| 凡俗一境 · 锻骨 | 夜半山门响，肩头抵得住。 | 初始境。站稳守式，有机会扛过第一次虎啸。 |
| 凡俗二境 · 舒筋 | 起如山鸟，落似老熊。 | 开身法位，基础退步在第 1、4、7…轮可避开河伯第一道浪。 |
| 凡俗三境 · 贯劲 | 一箭入石，满弓余声未歇。 | 解锁连式，守式成功架住重击后追加一次反击。 |
| 入道四境 · 听息 | 芦花无风动，水底有呼吸。 | 开神通位，先凭呼吸找到真身，再学妖的照影术。 |
| 入道五境 · 心斋 | 满堂皆鬼语，一念自澄明。 | 开放第二武学位，能把不同周期的武学排成连式。 |
| 入道六境 · 坐忘 | 山雨落空庭，忘身不忘刀。 | 可内化一门带内化条目的精通武学或身法，获得其弱化被动，与原招主动装配互斥。 |
| 仙途七境 · 御风 | 从前愁涧阔，今日过山轻。 | 巡夜路线延伸至云栈，能在空中追击飞妖。 |
| 仙途八境 · 真人 | 深潭沉月影，鼻息不惊波。 | 每战首次受到标记为妖术的致命伤时保留 1 点气血。有神通在位，则增强它下一次照谱释放的效果。 |
| 仙途九境 · 逍遥 | 万里夜将尽，提灯任去留。 | 指定的两门精通传承可合成本命招，卡面写明所属槽型和固定回合。可免费拆回。 |

|---|---|---|

## 破境与开图次序

每次突破都承接上一境并花道行。表中的主线门槛均可通过确定性事件完成。首卷以外的细案名和消耗可在制作时细化。

| 境界 | 剧情门槛与能力首次派上用场的地方 |
|---|---|
| 锻骨 | 开局已具备守夜人的基本功。普通短刀和守式可打赢山君。 |
| 舒筋 | 山君首胜后可入境。芦花渡先开放巡夜，挑战河伯时才检查舒筋。 |
| 贯劲 | 舒筋且渡口三条线索齐全即可突破。河伯允许在舒筋或贯劲挑战，两种顺序均可通向听息。 |
| 听息 | 贯劲且河伯首胜后可突破；先开放庙街巡夜，挑战娘娘才须听息。“船底第二重呼吸”是演出，无须随机掉书。 |
| 心斋 | 娘娘首胜开旧驿，听息即可挑战篙鬼；取回路引后入心斋。第二武学位和两组预设在此开放，有第二门武学时可排同轮连式。 |
| 坐忘 | 守更驿卒首胜取得交接签、送达家书，开云栈山脚。用心斋完成地面认风灯的调查后入坐忘。精通招式是使用内化的条件，突破本身只检查剧情与道行。 |
| 御风 | 坐忘后在可徒步抵达的下层栈道救回守灯人，取得完整风灯，方可入御风。此时才开放空中巡夜地和上层首领。 |
| 真人 | 御风平定天栈、与师父会合后开放总灯房外院。两册巡簿核对完成可入真人，第一次致命妖术出现在其后的内院。 |
| 逍遥 | 真人持各站应答完成内院守灯试炼后可入逍遥，再挑战终卷守灯妖。合成本命须拥有指定配对并双双精通；终战另留确定性基础配装胜路。 |

首卷装备上限为一武学、一身法、一神通；心斋起上限为两武学、一身法、一神通。坐忘只增一个内化位，真人只增保命反应，逍遥本命占一个既有主动位。合成期间两门来源传承从主动位和内化位一并卸下。技能效果如需调整，先核对首发轮、内化占用和首胜的基础解法，再改对应分册。

**锻骨与舒筋。** 锻骨是游戏对练身的概括。舒筋借导引之士模仿熊、鸟伸展身体的记载，美术可把伸展和落步做成破境动作。[《庄子·刻意》](https://zh.wikisource.org/wiki/莊子/刻意)

**贯劲。** 李广将草中之石当作虎，一箭入石，辨明之后再射却无法重现。取其中凝神贯力的一瞬，写成有条件触发的连式。[《史记·李将军列传》](https://zh.wikisource.org/wiki/史記/卷109)

**听息与心斋。** 取听之以气与心斋的意象。听息是原创境名，首次破境时把河声渐弱，留下船板下第二重呼吸。[《庄子·人间世》](https://zh.wikisource.org/wiki/莊子/人間世)

**坐忘与真人。** 坐忘借忘却形体的叙述，真人借其呼吸深沉的描写；游戏分别用来表现招式融入本能、危局中从容回息。[《庄子·大宗师》](https://zh.wikisource.org/wiki/莊子/大宗師)

**御风与逍遥。** 前者借列子御风而行，后者取游无穷之意。御风改变主角能抵达的地方，逍遥让她有能力留下自己的传承。[《庄子·逍遥游》](https://zh.wikisource.org/wiki/莊子/逍遙遊)
