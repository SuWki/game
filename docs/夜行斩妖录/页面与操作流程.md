# 首卷页面与操作流程

## 一晚从哪里开始，又在哪里结束

新档在黑风岭山道上。点「提灯夜行」遇一只小妖。第二只必掉松纹刀，夜行按钮让位给换装对照。穿戴或收入行囊后继续。第 3 只留下第一条线索，这时场景里的妖案入口才出现。第 12 只后可以挑战山君，也可以再练几刀。

首胜时，玩家在战果页悟得镇山喝，花 30 道行即可修习并装备，也可暂留招谱。山君牙坠可以当场戴上。准备好就点「前往芦花渡」。想留在黑风岭的玩家点「返回巡夜」，可继续手动或开启沿路巡夜，扫清后收灯。渡口和庙街沿用同一套操作。

## 页面、按钮与去向

| 所在处 | 玩家来这里做什么 | 按钮与结果 |
|---|---|---|
| 巡夜 | 走山道、寻线索、处理新收获 | 依进度突出「提灯夜行」「挑战某位大妖」「前往某地」。找到首领后仍可继续巡夜。线索未齐时显示离下一条还差几只，线索齐但境界不足时写明所需境界。关闭指引时仍显示这些状态。首胜山君后，沿路巡夜与收灯是一对开关。 |
| 妖案 | 确认当前地图查到了什么 | 点场景里的线索查看本地案情，达到条件可从案内挑战。开局第一条线索出现后才给入口。 |
| 装备 | 决定这件收获是否值得替换 | 新拾装备就地显示升降与失去的词条。穿戴或收入行囊均确认当前一件。点兵刃、护具或佩饰可再比较，收起或换装后回到原处。 |
| 招式 | 决定下一场带哪些本领 | 先看三个槽，再看待修习招谱。点击对应槽定位到招谱。修习并装备、仅修习、替换与精通均写明作用或费用。败阵后从这里可直接再战，按钮保留在配招页顶部，并写明对手。 |
| 修行 | 查多久能升层、还能花多少道行 | 点顶栏境界，看到本层进度、累计与可用道行、新境能力。有招谱待学时可以直接去招式页。 |
| 斩妖录 | 换路，或再会已胜的大妖 | 每个地点写明当前、可前往、已平息或未通行。锁住的地方直接写开路条件。已平息地点提供重演，当前地点能回巡夜。 |
| 照妖镜 | 首胜娘娘后推重数、养刻纹 | 从斩妖录进入。主按钮挑战下一重，也可输入已破的重数试招。淬纹砂在页首，刻纹可启纹、温养和切换。 |
| 卷末去处 | 首卷平定后选择下一次想做的事 | 娘娘战果及已平定的白烛庙首页都能直达。斩妖录先列两桩托付与照妖镜，原地图在「首卷旧案」内展开。手机上每个目的地整行可点。 |
| 异相托付 | 看目标、整装、出战 | 案前写明胜法和首成奖励。点行装换装备，进招式页可对照该案真实轮次，调完直接出战。战中灯格随行动结算，选招时先显示预计进度。战果留在本案，可读后日谈、再试或用首成奖励养纹。 |
| 大妖交锋 | 看敌招，决定要不要应变 | 在险招前看双方余血再选。可保留机会，撤退回到发起交锋的页面。装备与配招在战外调整。 |
| 战果 | 兑现收获，决定去哪 | 新招和装备可以当场处理。首胜开路后直接前往下一处，败阵可调整招式或再战。伤害记录和联动次数收进「交锋详情」。 |
| 指引 | 临时忘记操作时查一眼 | 顶栏可随时打开。先给当前建议，再按夜行、装备、交锋等主题展开。关闭后接着原先的操作。 |

## 返回与中断

- 三个常用页签是巡夜、招式、斩妖录。招式在首次找齐山君线索后出现，斩妖录在山君首胜后出现。手机长页保留顶部页签。
- 查看详情时，返回按钮写明目的地。从战果进入招式、再查看修行，逐级返回招式和原战果。点「巡夜」可随时回到所在地。交锋期间收起页签。
- 从斩妖录重演时，撤退回发起挑战的页面。战果保留回斩妖录的入口，经调整招式再战后也能回去。地图切换成功后落在目的地山道。
- 有装备待处理时，巡夜页签标「待整装」，逐件确认后才恢复原巡夜方式。大妖战和查看战果期间，已经开启的沿路巡夜暂歇，返回巡夜、斩妖录或换路后按原设置继续。刷新会回到存档中的巡夜地点。
- 三处地图按累计道行扫清。扫清后仍可挑战、重演、找回遗漏装备。关闭新手指引也会显示扫清状态和下一步。
- 查案从第一只小妖起显示下一条线索的进度条。已击败过的大妖可以切换一倍或两倍战速，险招仍停手等选择。异相、镜战及从两处进入的备战页暂停沿路巡夜。

## 试玩验收

第一次进入时能直接提灯。在不满黑风岭修行上限时打赢山君，返回山道仍能一键去渡口。从战果看招式、查看余额后，能回到同一份战果。已经打过河伯的玩家从斩妖录重演，败阵、调招、再战后，能回到斩妖录。关闭指引后，仍能看见缺几条线索或需要哪个境界。沿路巡夜中打赢大妖，在战果页停留也不会开始新一轮寻妖。

下一轮可用这句做试玩任务：“从首胜山君的战果出发，看看够不够学镇山喝，把它带上，然后去芦花渡。沿途记下每一次需要猜按钮或找返回入口的地方。”
