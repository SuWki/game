# 首卷页面与操作流程

## 一晚从哪里开始，又在哪里结束

新档在黑风岭山道上。点「提灯夜行」遇一只小妖。前两只内会拾到装备，夜行按钮让位给换装对照。穿戴或收入行囊后继续。第 3 只留下第一条线索，这时场景里的妖案入口才出现。第 12 只后可以挑战山君，也可以再练几刀。

首胜时，玩家在战果页悟得镇山喝，花 30 道行即可修习并装备，也可暂留招谱。山君牙坠可以当场戴上。准备好就点「前往芦花渡」。想留在黑风岭的玩家点「返回巡夜」，可继续手动或开启沿路巡夜，扫清后收灯。渡口和庙街沿用同一套操作。

## 页面、按钮与去向

| 所在处 | 玩家来这里做什么 | 按钮与结果 |
|---|---|---|
| 巡夜 | 走山道、寻线索、处理新收获 | 依进度突出「提灯夜行」「挑战某位大妖」「前往某地」。找到首领后仍可点「继续夜行」。首胜山君后，沿路巡夜与收灯是一对开关。 |
| 妖案 | 确认当前地图查到了什么 | 点场景里的线索查看本地案情，达到条件可从案内挑战。开局第一条线索出现后才给入口。 |
| 装备 | 决定这件收获是否值得替换 | 新拾装备就地显示升降与失去的词条。穿戴或收入行囊均确认当前一件。点兵刃、护具或佩饰可再比较，收起或换装后回到原处。 |
| 招式 | 决定下一场带哪些本领 | 先看三个槽，再看待修习招谱。点击对应槽定位到招谱。修习并装备、仅修习、替换与精通均写明作用或费用。败阵后从这里可直接再战。 |
| 修行 | 查多久能升层、还能花多少道行 | 点顶栏境界，看到本层进度、累计与可用道行、新境能力。有招谱待学时可以直接去招式页。 |
| 斩妖录 | 换路，或再会已胜的大妖 | 每个地点写明当前、可前往、已平息或未通行。锁住的地方直接写开路条件。已平息地点提供重演，当前地点能回巡夜。 |
| 大妖交锋 | 看敌招，决定要不要应变 | 在险招前看双方余血再选。可保留机会，撤退回到发起交锋的页面。装备与配招在战外调整。 |
| 战果 | 兑现收获，决定去哪 | 新招和装备可以当场处理。首胜开路后直接前往下一处，败阵可调整招式或再战。伤害记录和联动次数收进「交锋详情」。 |
| 指引 | 临时忘记操作时查一眼 | 顶栏可随时打开。先给当前建议，再按夜行、装备、交锋等主题展开。关闭后接着原先的操作。 |

## 返回与中断

- 三个常用页签是巡夜、招式、斩妖录。招式在首次找齐山君线索后出现，斩妖录在山君首胜后出现。手机长页保留顶部页签。
- 查看详情时，返回按钮写明目的地。从战果进入招式、再查看修行，逐级返回招式和原战果。点「巡夜」可随时回到所在地。交锋期间收起页签。
- 从斩妖录重演时，撤退或从战果返回都能继续翻原来的斩妖录。地图切换成功后落在目的地山道。
- 有装备待处理时，等待玩家作决定。连续几件逐件看完后才恢复原巡夜方式。学招和识图都可稍后进行。
- 三处地图按累计道行扫清。扫清后仍可挑战、重演、找回遗漏装备。关闭新手指引也会显示扫清状态和下一步。

## 试玩验收

第一次进入时能直接提灯。在不满黑风岭修行上限时打赢山君，返回山道仍能一键去渡口。从战果看招式、查看余额后，能回到同一份战果。已经打过河伯的玩家从斩妖录重演、撤退，再进一次时仍能找到原来的地点。

下一轮可用这句做试玩任务：“从首胜山君的战果出发，看看够不够学镇山喝，把它带上，然后去芦花渡。沿途记下每一次需要猜按钮或找返回入口的地方。”
