# 首卷页面与操作流程

## 一晚从哪里开始，又在哪里结束

新档在黑风岭山道上。第二只小妖必掉松纹刀，处理装备后可继续巡夜。第 3 只留下断爪印，打开场景里的妖案便能看见虎啸回合和前六回合招路。第 7 只留下夹齿，妖案写明可伏身避啸，此时即可挑战。愿意再斩五只的玩家可以备好灯油，第一次伏身后多打 8 点伤害。早打山君，首胜道行也足够修习镇山喝。

首胜时，阿照在战果页从虎啸里悟得镇山喝，花 30 道行即可修习并装备，也可暂留招谱。山君牙坠可以当场戴上。准备好就点「前往芦花渡」。渡口的第二条线索可直接查看「水下应铃」，证词和第 3 回合的截断提示在同一处。河伯首胜见到白烛庙旧灯，白烛庙首胜听陆婆说起对岸的铃声，点「随陆婆过河」到纸马驿。想留在当地可返回巡夜，故事也能在斩妖录回看。

## 页面、按钮与去向

| 所在处 | 玩家来这里做什么 | 按钮与结果 |
|---|---|---|
| 巡夜 | 走山道、寻线索、处理新收获 | 每条线索到手会短暂提示所得情报，场景入口保留最新进度。两条线索到手且境界达标后，可以挑战或继续巡夜备战。关闭指引时仍显示这些状态。 |
| 妖案 | 看招路、选应对、决定何时出战 | 第一条开放前六回合对照，显示按当前配装实算的触发与气血变化。第二条给出应对。实查第三条为正篇和强敌再战准备对应应对，在出战前说明伤害。扫清可开启挑战，仍可从再战第一关补齐线索。 |
| 线索指引 | 从发现线索一直找到对应招式 | 巡夜时在操作区下方显示当前线索。第一条直达招路对照，第二、三条直达妖案对应记录。查看或确认后只收起本条，下一条仍会提示。境界达标时会提示可以挑战。 |
| 装备 | 决定这件收获是否值得替换 | 新拾装备就地显示升降与失去的词条。穿戴或收入行囊均确认当前一件。点兵刃、护具或佩饰可再比较，收起或换装后回到原处。 |
| 招式 | 决定下一场带哪些本领 | 先看槽位，再看待修习招谱。点击对应槽定位到招谱。修习并装备、仅修习、替换与精通均写明作用或费用。从强敌再战进入时，对照该关的实际招路，配好可直接出战。 |
| 修行 | 查多久能升层、还能花多少道行 | 点顶栏境界，看到本层进度、累计与可用道行、新境能力。有招谱待学时可以直接去招式页。 |
| 斩妖录 | 换路，选择下一场强化挑战 | 每个地点写明当前、可前往、已平息或未通行。首胜后可以进「强敌再战」选对手。 |
| 强敌再战 | 用更难的首领换取旧装备强化 | 每个已胜首领各有三关。选首领后对照当前招路、气血、强化前后的装备数值，可换装和调招。守更高阶在战前与战中显示连续未破印。山君和河伯再战首关的战果可直达对应重铸。 |
| 照妖镜 | 推重数、养刻纹、检验配装 | 主按钮挑战下一重，输入已破重数也能对照实招并按该重出战。两次连续挑战同一重时对比结果。刻纹和已开放的重铸都完成后，爬重继续记录，淬纹砂停止增加。 |
| 旧装重铸 | 决定先提高哪件装备的基础属性 | 从照妖镜进入。松纹刀和渡水蓑分别显示主线和再战前置、重铸前后数值与砂耗。完成后可直接看原装备，穿戴状态随存档保留。 |
| 青芦卷末 | 首卷平定后接托付或养刻纹 | 娘娘战果可直达斩妖录。纸马驿下方列两桩托付和照妖镜，原地图在「首卷旧案」内展开。手机上每个目的地整行可点。 |
| 纸马驿 | 接续主线，查驿桥的半声铃 | 娘娘首胜战果、白烛庙首页和斩妖录都可「随陆婆过河」。听息且找到第二条线索即可挑战篙鬼。首胜可就地修习折篙刀和佩戴路引。 |
| 驿路送信 | 送灯到纸马院，寻回守更楼的家书 | 驿桥首胜后可去纸马院，纸马首胜开放守更楼。两案战场分别显示马灯、更印与符印，选招前预估双方余血。送达家书后可从斩妖录继续做异相、强敌再战和照妖镜。 |
| 两套配装 | 把常用武学、装备与刻纹存成可切换组合 | 心斋后从行装或招式页展开「两套配装」，填名并保存当前。保存后点配装名即应用，展开「保存与命名」可以覆盖为当前。切换会进存档，战中锁定开场配装。 |
| 异相托付 | 解一道地方难题，把应对带进镜战 | 案前可看胜法和选招进度。首成后结案，可读后日谈，去照妖镜试用本案对应的准备。还没查明第三条线索时，镜中给出补查入口。 |
| 战前准备 | 确认当前配装能否过关 | 首领战都经此页，按当前配置推演到实际结算，显示胜负、回合和余血或败因。可以直接出战。败阵时可展开「对照可过的配装」，最多显示两套实算通过的方案，修习费用写在应用按钮上。手动整备也会同步更新胜负，返回原对手和关卡。 |
| 大妖交锋 | 看敌招、配招有没有接上 | 当轮招式和机制在战场结算，战报记录触发。可切换演出速度或撤退回到发起交锋的页面。 |
| 战果 | 兑现收获，决定去哪 | 新招和装备可以当场处理。首胜开路后直接前往下一处。败阵先看这场实际原因，再从建议直接调整装备、招式或架势。镜中旧重能从战果原层重试。伤害记录和联动次数收进逐回合战报。 |
| 指引 | 临时忘记操作时查一眼 | 顶栏可随时打开。先给当前建议，再按夜行、装备、交锋等主题展开。关闭后接着原先的操作。 |

## 界面取舍

| 之前的问题 | 现在如何操作 |
|---|---|
| 空槽位点了可能找不到招式，未悟得的卡片占屏 | 有招可选的槽才可点击。遗漏传承从对应首领的强敌再战首关补齐。换招会覆盖已有招式时才提供「仅修习」。听潮步也可留在招谱，以便保留原有退步。 |
| 换装只比较词条，容易以为穿上就生效 | 掉落卡与行囊同时显示数值变化和缺少的搭配。松纹刀的效果需要镇山喝成功截断，纸马灯芯需要引爆寄灯符。扫清后从强敌再战找回的本地装备会注明来源。 |
| 缺道行时把未开地图当作可去之处，地图上限难以换算 | 修行页直接显示本地还能取得多少道行，扫清后给出已开路线或可挑战的首领。招式费用说明区分已可前往、还要开路和现有额度不足。 |
| 刻纹温养前看不到效果，交锋中重复两处流水 | 启纹显示初始收益，下一纹写进温养按钮，缺砂显示差额。交锋只保留双方变化和回合上限，完整事件可在战果中展开。败阵优先给出覆舟、落桥、反噬或回合耗尽等实际原因。 |

## 返回与中断

- 三个常用页签是巡夜、招式、斩妖录。第一条山君线索开放招式页和斩妖录。手机长页保留顶部页签。
- 查看详情时，返回按钮写明目的地。从战果进入招式、再查看修行，逐级返回招式和原战果。点「巡夜」可随时回到所在地。交锋期间收起页签。
- 强敌再战撤退会回到发起挑战的页面。结算停在对应首领页，可以查看强化后的装备或调整配装。地图切换成功后落在目的地山道。
- 有装备待处理时，巡夜页签标「待整装」，逐件确认后才恢复原巡夜方式。大妖战和查看战果期间，已经开启的沿路巡夜暂歇，返回巡夜、斩妖录或换路后按原设置继续。刷新会回到存档中的巡夜地点。
- 各地图按累计道行扫清。扫清后仍可挑战和强敌再战，找回遗漏装备。修行页会指向可巡得道行的地图或已开放且未结的妖案。已开路线按首胜记录保留。关闭新手指引也会显示扫清状态和下一步。
- 查案从第一只小妖起显示下一条线索的进度条。所有首领战都可切换一倍或两倍战速。战前弹窗和对应配装页暂停沿路巡夜。重铸要求的地图未开时，入口指到当前能走的前置地图。
- 心斋开启第二武学位，招式页两格依实际出招顺序排列。点「互换武学顺序」同时更新战前预览，下一场交锋生效。纸马驿战中显示失足格，借墩稳身触发后能看到失足清零。

## 战场站位

六处战场的站位以背景原图的地面为准。黑风岭站在石径、芦花渡站在木台，白烛庙、驿桥、纸马院、守更楼站在各自的石板前沿。背景以底部对齐裁切，脚底和影子随同一个缩放比例定位。待机从脚底向上轻微伸缩，出刀和受击沿地面移动。验收同时看窄屏巡夜、宽屏巡夜及高度较短的首领战。

## 试玩验收

第一次进入时能直接提灯。在不满黑风岭修行上限时打赢山君，返回山道仍能一键去渡口。从战果看招式、查看余额后，能回到同一份战果。已经打过河伯的玩家从斩妖录重演，败阵、调招、再战后，能回到斩妖录。关闭指引后，仍能看见缺几条线索或需要哪个境界。沿路巡夜中打赢大妖，在战果页停留也不会开始新一轮寻妖。

下一轮可用这句做试玩任务：“从首胜山君的战果出发，看看够不够学镇山喝，把它带上，然后去芦花渡。沿途记下每一次需要猜按钮或找返回入口的地方。”
