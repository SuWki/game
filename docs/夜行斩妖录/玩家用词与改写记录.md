# 玩家用词与改写记录

写指引时，先让玩家看见一个征兆，再告诉他此刻能做什么。沿用这一句作参照：“听息让阿照在烛火偏转时辨出娘娘真身。悟得神通后，可以在「招式」页修习和装备。”按钮写动作。血量、代价和回合照实用数字表示。

| 原用词 | 玩家看到的词 | 使用位置与含义 |
|---|---|---|
| 自动夜行／停止自动 | 沿路巡夜／收灯歇脚 | 山君首胜后，阿照可一路寻妖。新装备入手时驻足整装。 |
| 余下险招不停手／险招前停手 | 开始交锋 | 战前安排好应对后开始。交锋按回合自动执行。 |
| 正常出招／本轮照谱 | 不安排 | 该应对位留空，已配的招式仍会按回合出手。 |
| 低头防守／抢先砍一刀 | 伏身避啸／迎啸进刀 | 招名跟随山君的动作。改变计划后，双方气血条会重新推演。 |
| 学习 · 30／未习得 | 已悟得 · 待修习／修习并装备 · 30 道行／仅修习 · 30 道行 | 把到手的招谱和学会后能带入战斗的招式显示成不同状态。每类槽位写清当前带的招或开启境界。 |
| 自动施放 | 第几回合出手、每隔几回合再出招 | 指引保留招式的具体轮次。 |
| 待命／新装备提示 | 待提灯／驻足整装 | 对应还没出发、或拾得装备等玩家处理。 |
| 立即穿戴／先收好 | 穿戴／收入行囊 | 两者均处置当前一件。只在全部处置后恢复先前巡夜方式。 |
| 装备提升／战力更高 | 刀伤、气血上限及 ↑ ↓；获得、失去 | 数值用实际架势计算。每项词条保留触发条件，玩家能判断换装代价。 |
| 自动升级／第五胜保底 | 道行积满便升一层／强敌再战首关可补悟 | 分别用于修行页和传承入口。 |

新加的词若涉及相同操作，在此表补上原词、实际显示和生效范围。装备说明可用数字说清差别，首领交锋优先用血条和回合预览，长解释留在指引或交锋详情。
